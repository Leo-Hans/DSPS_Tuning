## 1. 研究概述

分布式流处理系统的性能受到参数配置、输入负载、算子拓扑及集群资源等因素的共同影响。人工调参通常需要多轮实验，不同配置之间的效果也可能随着运行条件变化。

本研究关注以下问题：

- 如何定义有效的参数搜索空间与配置约束？
- 如何在有限实验预算内找到满足目标的配置？
- 如何公平评估调参效果，并保证实验可复现？
